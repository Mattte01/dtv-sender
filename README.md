# DTV Sender · Web

Herramienta de difusión masiva de WhatsApp para Connection Center DirecTV.

## Uso

Abrí [https://Mattte01.github.io/dtv-sender](https://Mattte01.github.io/dtv-sender) en tu browser.

## Funcionalidades

- **SpinTax**: `{opción A|opción B}` para variantes de texto
- **IA integrada**: reformulación de mensajes con Claude (Anthropic)
- **Anti-ban**: delay configurable entre mensajes + pausa larga automática
- **Firmas y emojis rotativos**

## Configurar GitHub Pages

1. Ir a Settings → Pages
2. Source: Deploy from branch → main → /root
3. La página queda en `https://Mattte01.github.io/dtv-sender`
